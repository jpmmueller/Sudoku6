Hat geklappt. Was bedeuten deine Kommentare in diesen 3 Zeilen die ich gerade geändert habe?

Zeilen:
1️⃣ const idx = v - 1;

Deine Kandidatenzahl v geht von 1 bis 9.
Für Berechnungen ist aber ein Index von 0 bis 8 oft praktischer.

Deshalb:

v = 1 → idx = 0

v = 2 → idx = 1

…

v = 9 → idx = 8

2️⃣ const gridRow = Math.floor(idx / 3); // 0 = oben, 2 = unten

Hier wird berechnet, in welcher Zeile des 3×3-Kandidatenrasters die Zahl landen soll.

Beispiel:

Zahl	idx	   idx / 3	  floor	 gridRow
1   	0	   0.0	        0	   0
2	    1	   0.33         0	   0
3	    2	   0.66	        0	   0
4	    3	   1.0	        1	   1
5	    4	   1.33	        1	   1
6	    5	   1.66	        1	   1
7	    6	   2.0	        2	   2
8	    7	   2.33	        2	   2
9	    8	   2.66	        2	   2

👉 Das ergibt ein Raster:

gridRow 0 → [1 2 3]
gridRow 1 → [4 5 6]
gridRow 2 → [7 8 9]


bedeutet einfach:

0 ist die oberste Kandidatenreihe

2 ist die unterste Kandidatenreihe


Spalten:

3️⃣ const gridCol = idx % 3; // 0 = links, 2 = rechts

Hier wird die Spalte im 3×3 Kandidatengitter berechnet.

Modulo % bedeutet: „Rest bei Division durch 3“.

Beispiel:

| Zahl | idx | idx % 3 | gridCol |
| ---- | --- | ------- | ------- |
| 1    | 0   | 0       | 0       |
| 2    | 1   | 1       | 1       |
| 3    | 2   | 2       | 2       |
| 4    | 3   | 0       | 0       |
| 5    | 4   | 1       | 1       |
| 6    | 5   | 2       | 2       |
| 7    | 6   | 0       | 0       |
| 8    | 7   | 1       | 1       |
| 9    | 8   | 2       | 2       |

Gibt wieder ein Raster:

gridCol 0 → links
gridCol 1 → mitte
gridCol 2 → rechts

Und deshalb der Kommentar:
// 0 = links, 2 = rechts
